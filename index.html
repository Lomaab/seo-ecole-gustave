📋 Plan d'Action Concret

Étape par étape — quoi faire exactement dans WordPress

Instructions détaillées pour chaque correction, avec captures d'écran mentales et chemins exacts dans WordPress.

SEMAINE 1 Quick Wins — ~30 min

1 Ajouter la meta description sur la page formation Paris ▼

Où : /formation-plombier-chauffagiste-paris/

Problème : Aucune meta description → Google affiche un extrait aléatoire peu attractif.

Dans WordPress + Yoast :

  1. Aller dans Pages → Toutes les pages
  2. Rechercher "formation plombier chauffagiste paris"
  3. Cliquer sur Modifier
  4. Descendre jusqu'au bloc Yoast SEO (sous l'éditeur)
  5. Onglet "Google Preview" ou "Snippet Editor"
  6. Dans le champ Meta description, coller :
Formation plombier chauffagiste à Paris — Titre RNCP niveau 4. Accessible en alternance, financement possible. 6 mois de formation pratique. Taux d'insertion : 85%.
💡 La meta description n'influence pas directement le classement, mais elle augmente le CTR de 15 à 30%. Sur 10 000 impressions, passer de 1% à 2% de CTR = +100 clics.
2 Optimiser le titre et H1 de la formation Paris ▼

Où : /formation-plombier-chauffagiste-paris/

Problème : Le titre et H1 actuels sont faibles. Pas de mots-clés "RNCP", "alternance", "certification".

Dans WordPress + Yoast :

  1. Dans l'éditeur de la même page
  2. Modifier le titre de la page (en haut de l'éditeur) :
Titre SEO (via Yoast) : Formation Plombier Chauffagiste Paris | RNCP | Alternance
  1. Modifier le H1 dans le contenu de la page :
H1 : Devenir Plombier Chauffagiste à Paris — Formation RNCP en Alternance

Raison : Google utilise le titre dans le résultat de recherche. "RNCP" et "Alternance" sont des mots-clés qui rassurent et convertissent.

3 Ajouter les alt texts sur les images ▼

Où : Toutes les pages (14 images sans alt text détectées)

Problème : Google Images ne peut pas classer ces images, elles ne rapportent pas de trafic.

Dans WordPress :

  1. Aller dans Média → Bibliothèque
  2. Passer en mode Liste (en haut à droite)
  3. Trier par "Non utilisé" ou cliquer sur chaque image sans alt text
  4. Dans le panneau latéral droit, remplir le champ Texte alternatif
  5. Exemples :
"Campus École Gustave Lyon - atelier formation plomberie" "Élèves en formation plombier chauffagiste au campus Paris" "Certificat RNCP formation plombier École Gustave" "Salle de formation pratique électricien École Gustave"
4 Convertir les images en WebP ▼

Où : 20 images au format JPEG/PNG à convertir

Problème : Le poids des images ralentit le chargement et pénalise le score de performance.

Méthode automatique (recommandée) :

  1. Dans WordPress, aller dans Extensions → Ajouter
  2. Rechercher et installer "WebP Express" ou "ShortPixel" (gratuits)
  3. Activer l'extension
  4. Aller dans Réglages → WebP Express
  5. Cocher "Convertir automatiquement les images au format WebP"
  6. Choisir qualité 80 (bon équilibre qualité/poids)
  7. Enregistrer

Méthode manuelle : Utiliser squoosh.app (gratuit) pour convertir les images une par une, puis les remplacer dans la médiathèque.

SEMAINE 2 Contenu — ~4h

1 Consolider les 2 pages formation plombier en 1 seule ▼

Pourquoi : Actuellement, 2 pages principales cannibalisent le mot-clé "formation plombier" :

  • /formation-plombier-chauffagiste-paris/ (4 154 imp, pos 11.4)
  • /formations/formation-plombier-chauffagiste/ (3 548 imp, pos 12.9)

Objectif : N'avoir qu'une seule page qui cumule toute l'autorité et monte en position ~3.

Dans WordPress :

  1. Conserver /formation-plombier-chauffagiste-paris/ comme page principale
  2. Fusionner le contenu : copier tout le meilleur contenu de la page secondaire vers la page principale
  3. Installer l'extension "Redirection" (gratuite, par John Godley)
  4. Aller dans Outils → Redirections
  5. Cliquer sur "Ajouter une redirection"
  6. Source URL : /formations/formation-plombier-chauffagiste/
  7. Target URL : /formation-plombier-chauffagiste-paris/
  8. Sélectionner 301 — Moved Permanently
  9. Cliquer sur "Ajouter la redirection"
  10. Dans Yoast SEO sur la page secondaire, définir la balise canonical vers la page principale
⚠️ Une fois fait, aller dans Google Search Console → Inspection d'URL, coller l'URL de la page principale et cliquer sur "Demander l'indexation" pour accélérer la prise en compte.
2 Enrichir le contenu formation plombier (pour top 3) ▼

Pourquoi : La page est en position 11.8. Pour passer top 3, il faut un contenu plus complet que les concurrents.

Éléments à ajouter :

  1. FAQ (10 questions) avec schéma FAQ — ex : "Quel est le salaire d'un plombier chauffagiste ?", "La formation est-elle éligible au CPF ?", etc.
  2. Témoignages élèves avec photo et prénom — format : "Grâce à l'École Gustave, j'ai obtenu mon titre RNCP en 6 mois"
  3. Section "Pourquoi choisir l'École Gustave ?" — 3-4 arguments clés avec icônes
  4. Tableau des débouchés avec salaires :
| Métier | Salaire débutant | Salaire après 5 ans | |---------------------|------------------|---------------------| | Plombier chauffagiste | 2 100 € net | 3 500 € net | | Chef d'équipe | 2 800 € net | 4 200 € net |
  1. Vidéo YouTube du campus ou d'une démo pratique (intégrer via le bloc WordPress "YouTube")
  2. CTA final : bouton "Demander une brochure" ou "Réserver un appel" — avec ancre vers formulaire de contact

Pour Yoast SEO : viser le feu vert sur tous les points (lisibilité, mots-clés, liens internes).

3 Ajouter le schéma LocalBusiness sur chaque campus ▼

Pourquoi : Le schéma LocalBusiness permet à Google d'afficher les infos du campus directement dans les résultats (adresse, note, horaires).

Dans Yoast SEO :

  1. Aller dans Yoast SEO → Réglages → Général → Site
  2. Type d'organisation : LocalBusiness
  3. Remplir les infos générales de l'école

Pour chaque page campus (méthode manuelle si Yoast ne gère pas le multi-schema) :

  1. Installer l'extension "Insert Headers and Footers" ou "WPCode" (gratuite)
  2. Aller dans Code Snippets → Ajouter un snippet
  3. Choisir "Ajouter du code personnalisé"
  4. Type : JavaScript (ou plutôt "PHP" si conditionnel)
  5. Coller pour chaque campus le JSON-LD adapté :
<script type="application/ld+json"> { "@context": "https://schema.org", "@type": "LocalBusiness", "name": "École Gustave Lyon", "address": { "@type": "PostalAddress", "addressLocality": "Lyon", "addressCountry": "FR" }, "url": "https://ecole-gustave.com/campus/lyon/" } </script>

Ou bien utiliser l'extension "Schema & Structured Data for WP & AMP" qui permet de gérer le schéma par page via l'interface.

4 Ajuster les pages qui cannibalisent la marque ▼

Pages concernées : /ecole-gustave/, /campus/*, /les-formations/

Problème : Ces pages apparaissent sur la requête "ecole gustave" avec un CTR de 0.6-2%, alors que la homepage fait 24.4%.

Dans Yoast SEO :

  1. Pour chaque page concernée, aller dans l'éditeur
  2. Descendre au bloc Yoast SEO
  3. Dans l'onglet "Focus keyphrase", supprimer la keyphrase "ecole gustave" si elle est définie
  4. Remplacer par la keyphrase spécifique à la page (ex: "campus lyon ecole gustave")
  5. Dans le titre SEO (via Yoast), retirer "École Gustave" du début — ex: "Campus Lyon | École Gustave" → mettre l'école en second

Alternative plus poussée : Ajouter noindex sur les pages qui n'ont pas vocation à être trouvées via la marque. Dans Yoast, onglet "Avancé" → "Indexation" → "Noindex".

SEMAINE 3 Technique — ~5h

1 Corriger le scroll horizontal mobile ▼

Problème : Le site a un scroll horizontal sur mobile (contenu qui dépasse de la largeur de l'écran).

Solution via Cloudflare (Edge) ou via le thème :

Option 1 — CSS direct (recommandé) :

  1. Aller dans Apparence → Personnaliser → CSS additionnel
  2. Ajouter :
html, body { overflow-x: hidden !important; width: 100% !important; }

Option 2 — Cloudflare :

  1. Se connecter au tableau de bord Cloudflare
  2. Aller dans Rules → Transform Rules → Modify Response Header
  3. Pas nécessaire pour ce correctif — le CSS suffit
2 Ajouter les headers de sécurité via Cloudflare ▼

Problème : Headers de sécurité manquants (X-Frame-Options, X-Content-Type-Options, Referrer-Policy, CSP).

Solution via Cloudflare :

  1. Se connecter au tableau de bord Cloudflare
  2. Aller dans Rules → Transform Rules → Modify Response Header
  3. Cliquer sur "Ajouter une règle"
  4. Nom : "Sécurité Headers"
  5. Champ "If" : laisser vide (appliqué à toutes les requêtes)
  6. Ajouter les headers suivants :
X-Frame-Options: SAMEORIGIN X-Content-Type-Options: nosniff Referrer-Policy: strict-origin-when-cross-origin Permissions-Policy: geolocation=(), microphone=(), camera=()

Alternative sans Cloudflare : Utiliser un plugin WordPress comme "HTTP Headers" (gratuit) ou ajouter via le fichier .htaccess.

3 Améliorer la lisibilité Flesch (19.7 → 60+) ▼

Problème : Score Flesch de 19.7 (très difficile à lire). Le texte contient trop de phrases longues et de mots complexes.

Solutions :

  1. Dans Yoast SEO, l'onglet "Lisibilité" vous montre les problèmes spécifiques
  2. Raccourcir les phrases à moins de 20 mots
  3. Diviser les paragraphes longs (max 4-5 lignes)
  4. Ajouter des listes à puces (comme ici)
  5. Utiliser des mots plus courts et plus courants
  6. Ajouter des sous-titres (H2, H3) tous les 2-3 paragraphes
  7. Mettre en gras les mots-clés importants
❌ Avant (Flesch ~20) : "La formation de plombier chauffagiste dispensée au sein de notre établissement vous permettra d'acquérir l'ensemble des compétences nécessaires à l'exercice de ce métier en plein essor dans le secteur du bâtiment et des travaux publics." ✅ Après (Flesch ~65) : "Devenez plombier chauffagiste en 6 mois. La formation est accessible en alternance. Vous obtenez un titre RNCP niveau 4. Les débouchés sont nombreux : 85% de nos diplômés trouvent un emploi dans les 3 mois."
4 Ajouter dimensions width/height sur toutes les images ▼

Problème : Les images sans dimensions explicites provoquent un Cumulative Layout Shift (CLS) — Google pénalise.

Solution avec un plugin :

  1. Installer l'extension "Enable Media Replace" ou "Auto Image Attributes"
  2. Les dimensions sont automatiquement ajoutées aux images lors de l'insertion
  3. Alternative : un plugin comme "Fixed CLS" ou "Speculative Loading"

Vérification : Après correction, tester avec PageSpeed Insights — le CLS devrait être < 0.1.
